## Core Architectural Principles (Current Era)

**1. Existing Public Primitives First** — Build world-class UI/UX and client-side systems on top of `atomicassets`, `alcorammswap`, Hyperion, WharfKit, etc.
**2. Client-Side State & Local-First** — Hyperion + encrypted local storage as source of truth.
**3. On-Chain Entropy** — TX hash + block header derivation for verifiable mechanics.

Future custom `pixel-journey` contracts will meet a very high bar.
