Pixel Journey blends serious Web3 engineering with joyful retro pixel culture. This codex ensures every package, dApp, template, educational blueprint, and piece of content meets a consistently elite bar in strategy, code quality, documentation, educational value, UI/UX, security, and alignment with our principles.

## Core Architectural Principles (Current Era)

**1. Existing Public Primitives First** — Build excellent UI/UX and client-side systems on top of public WAX/Antelope infrastructure.
**2. Client-Side State & Local-First** — Hyperion + encrypted local storage as source of truth.
**3. On-Chain Entropy** — TX hash + block header derivation for verifiable mechanics.

Future custom contracts will meet a high bar.
