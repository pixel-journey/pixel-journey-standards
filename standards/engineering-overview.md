# Engineering Standards Overview

Part of the Pixel Journey Development Framework.

## Core Principles
- Write clear, maintainable, secure code tailored to Web3 and pixel-art ecosystems.
- Prioritize performance, especially for on-chain and generative elements.
- Ensure consistency across the org through templates and reviews.

## Key Practices
- **Code Style**: Use consistent formatting, meaningful names, modular architecture.
- **Security**: Follow Web3 best practices (wallet handling, transaction safety).
- **Testing**: Comprehensive unit/integration tests, including visual for assets.
- **Performance**: Optimize renders, data fetching, and on-chain interactions.

## Checklists
- [ ] Follow repo template
- [ ] Run linters and tests
- [ ] Security review for Web3 components
